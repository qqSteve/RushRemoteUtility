# RushRemoteUtility для Windows x64

Исходники клиента на основе RustDesk 1.4.6 (1abc897c451c8b5bbff3792509a7fef9d12f2ce3). Код hbb_common включён в libs/hbb_common (48c37de3e6c4e399af6f51ca20e8e3e1fd037976). Лицензия и уведомления авторов сохранены. Основное окно, имя службы и сведения о продукте используют RushRemoteUtility. По умолчанию включена встроенная тёмная тема. Её можно изменить в настройках. 

## Сборка EXE через GitHub Actions

1. Распакуйте архив. Создайте пустой приватный репозиторий GitHub. Через Git или GitHub Desktop добавьте содержимое папки RushRemoteUtility в корень репозитория, включая скрытую папку .github. Отправьте коммит в основную ветку.
2. Для семейного сервера установите на VPS серверы hbbs и hbbr по инструкции https://rustdesk.com/docs/en/self-host/rustdesk-server-oss/docker/ . Настройте сетевые порты по этой инструкции. Скопируйте адрес VPS и содержимое файла id_ed25519.pub. Файл id_ed25519 — закрытый ключ, храните его только на VPS.
3. В Actions откройте RushRemoteUtility Windows x64 → Run workflow. Укажите домен или IPv4 сервера и его публичный ключ. На приватном репозитории сборка расходует минуты GitHub Actions. Процесс загружает инструменты и зависимости через интернет.
4. После успешной сборки скачайте артефакт RushRemoteUtility-Windows-x64. Распакуйте RushRemoteUtility.exe. Это самораспаковывающийся клиент без цифровой подписи издателя.

## Первое подключение

На своём тестовом ПК запустите EXE и установите клиент через его окно, чтобы работала служба Windows. В настройках безопасности разблокируйте изменение параметров, выберите подтверждение по паролю и использование постоянного пароля. Задайте уникальный пароль для этого ПК. Запишите его ID.

На iPhone откройте RustDesk, в настройках сети укажите тот же ID-сервер и публичный ключ. Для проверки выключите Wi-Fi на телефоне, подключитесь по ID и паролю и проверьте управление. Перезагрузите ПК и повторите подключение на экране входа Windows. На компьютерах родственников настройте доступ с их согласия и задайте для каждого отдельный пароль.

В архиве исходный проект и сценарий сборки. Сборка EXE, установка службы и подключение с iPhone требуют отдельной проверки.
